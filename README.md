# fit check

อัปโหลดรูปสูงสุด 12 รูป (รูปคนใส่ชุด หรือถ่ายเสื้อผ้าทีละชิ้น) → YOLOv8 ตรวจเสื้อผ้า 16 คลาส → ประเมินสไตล์ 6 แบบ → จับคู่ทุกชิ้นแล้วจัดอันดับชุดที่เข้ากันที่สุด

## โครงสร้าง

```
fitcheck/
├── best.pt            ← วางโมเดลของคุณที่นี่
├── main.py            ← FastAPI (โหลดโมเดล, รับรูป, เสิร์ฟหน้าเว็บ)
├── fitcheck.py        ← ตรรกะทั้งหมด (look check, style scoring, mix & match)
├── test_logic.py      ← เทสต์ตรรกะ ไม่ต้องใช้โมเดล
├── requirements.txt
└── static/index.html  ← หน้าเว็บ (หน้าแรก, อัปโหลด, กรอบ detection, ผลสไตล์, ชุดที่จัดให้, แนะนำ 6 สไตล์, จุดขาย AI)
```

## รัน

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp /path/to/best.pt .
uvicorn main:app --reload
```

เปิด http://127.0.0.1:8000 (เอกสาร API อัตโนมัติที่ /docs)

ตัวแปรสภาพแวดล้อม (ไม่บังคับ): `MODEL_PATH` (ค่าเริ่มต้น `./best.pt`), `IMGSZ` (640), `MAX_MB` (10), `MAX_FILES` (12)

ตอนสตาร์ท เซิร์ฟเวอร์จะเทียบชื่อคลาสในโมเดลกับ mapping ให้ ถ้าไม่ตรงจะเตือนใน log
ชื่อคลาสไม่สนตัวพิมพ์เล็ก/ใหญ่ และ `-` กับ `_` ถือว่าเหมือนกัน (`tank-top` = `Tank_Top`)

## ตรรกะ

**Look check** `เจอเดรส` หรือ `เจอท่อนบน + ท่อนล่าง` = ครบ / เจอแต่ท่อนบน = ขาดท่อนล่าง /
เจอแต่ท่อนล่าง = ขาดท่อนบน / เจอแต่สูท = ขาดทั้งสอง / ไม่เจออะไร = ตรวจไม่พบ
(ถ้าเจอเดรสพร้อมเสื้อหรือกางเกง จะขึ้นคำเตือนว่าอาจตรวจซ้ำ)

**Style score** `score[สไตล์] = Σ conf × (1 / จำนวนสไตล์ที่ไอเทมนั้นอยู่)` แล้วทำเป็นเปอร์เซ็นต์
ถ้าที่หนึ่งกับที่สองห่างกันน้อยกว่า 10% จะแสดงเป็นผสม เช่น `Hyperpop × Y2K`

**กรอบซ้ำ** กรอบหมวดเดียวกันที่ซ้อนกันเกิน 60% (IoU) จะเหลือกรอบที่ conf สูงกว่า
เช่น baby_tee กับ short_sleeve_top บนเสื้อตัวเดียวกัน แต่เสื้อคลุมทับเสื้อข้างในไม่ถือว่าซ้ำ

**Mix & match** รวมทุกชิ้นที่ตรวจเจอจากทุกรูป (สูงสุด 12 รูป) เป็นตู้เสื้อผ้า ไม่จำกัดหมวดละชิ้นต่อรูป และไม่สนว่าชิ้นมาจากรูปไหน
สร้างชุด `ท่อนบน + ท่อนล่าง` หรือ `เดรส` ทุกแบบที่เป็นไปได้ (เสริมสูทถ้าคะแนนดีขึ้น) แล้วจัดอันดับตามคะแนน 0–100
= สัดส่วนชิ้นที่อยู่ในสไตล์ที่ชนะ × ความมั่นใจเฉลี่ย (≥85 เข้ากันมาก, ≥60 เข้ากัน, ≥40 ลองดูได้)
แสดง 12 อันดับแรก และชุดที่ใช้คลาสเหมือนกันเป๊ะแสดงได้ไม่เกิน 2 อัน (`MAX_PER_SIGNATURE`) กันผลซ้ำกันทั้งหน้า

ปรับ mapping สไตล์ที่ `STYLES` และค่าต่าง ๆ (`TIE_MARGIN`, `DUP_IOU`) บนสุดของ `fitcheck.py` ได้เลย ไม่ต้องเทรนใหม่

## API

`POST /api/analyze?conf=0.45` — multipart field `files` (1–12 รูป), `ref` รูปเรฟ 1 รูป (ไม่บังคับ), `target_style` สไตล์ที่อยากได้ (ไม่บังคับ)

```json
{
  "outfits": [{
    "index": 0, "filename": "a.jpg",
    "detections": [{"cls": "baby_tee", "category": "top", "conf": 0.91, "box": [0.2, 0.1, 0.8, 0.45]}],
    "look": {"status": "complete", "missing": [], "message": "ชุดครบ", "warning": null},
    "style": {"label": "Hyperpop × Y2K", "styles": ["Hyperpop", "Y2K"], "scores": {"Y2K": 41.2, "...": 0}}
  }],
  "mixmatch": [{
    "items": [{"cls": "baby_tee", "outfit": 0, "category": "top", "conf": 0.91, "box": [0,0,1,1]},
              {"cls": "mini_skirt", "outfit": 1, "category": "bottom", "conf": 0.88, "box": [0,0,1,1]}],
    "style": {"label": "Hyperpop × Y2K", "styles": ["Hyperpop", "Y2K"], "scores": {}},
    "score": 92, "verdict": "เข้ากันมาก"
  }]
}
```
`box` เป็นสัดส่วน 0–1 ของรูป [x1, y1, x2, y2]  ·  `GET /api/styles` รายชื่อไอเทมของแต่ละสไตล์ (หน้าเว็บใช้สร้างการ์ดแนะนำสไตล์ จึงตรงกับ `STYLES` เสมอ) · `GET /api/health` ดูโมเดลและคลาสที่โหลด

## ข้อควรรู้

- รูปจะถูกประมวลผลในหน่วยความจำและไม่ถูกบันทึก ถ้าเปิดให้คนอื่นใช้ ควรบอกผู้ใช้เรื่องนี้และใส่ HTTPS
- คลาสที่หน้าตาใกล้กัน (`mini_pants` / `low_rise_pants` / `long_pants`, `baby_tee` / `short_sleeve_top`) ลองปรับ conf ถ้าสับสนบ่อย
- ถ้าอยากเพิ่ม cardigan / hoodie / denim jacket ต้องเทรนคลาสใหม่ แล้วเพิ่มใน `OUTERWEAR` กับ `STYLES` ใน fitcheck.py

## ปรับหน้าตาหน้าเว็บ

ข้อความจุดขาย AI อยู่ใน section `#ai` ของ `static/index.html` ส่วนสีและคำอธิบายของแต่ละสไตล์อยู่ในตัวแปร `STYLE_META` ใน `<script>`
ถ้าเพิ่มสไตล์ใหม่ใน `STYLES` ของ `fitcheck.py` ให้เพิ่มรายการใน `STYLE_META` ด้วย (ไม่เพิ่มก็แสดงได้ แต่จะเป็นการ์ดสีขาว)


## เรฟ (ไม่บังคับ)

ผู้ใช้เลือกได้ 3 แบบ: ไม่มีเรฟ / อัปรูปเรฟ / เลือกสไตล์ที่อยากได้
- มีเรฟ: AI ตรวจรูปเรฟด้วยโมเดลเดียวกัน แล้วเรียงชุดตาม "ใกล้เรฟ" = 60% สไตล์ที่คล้ายกัน (cosine ของคะแนนสไตล์) + 40% ชิ้นที่ตรงกัน
  (ชิ้นเดียวกับในเรฟได้เต็ม ชิ้นที่อยู่ในสไตล์ของเรฟได้ครึ่ง) ปรับได้ที่ `match_target` ใน fitcheck.py
- ผลมี `suggestions` บอกชิ้นที่ควรหาเพิ่ม เมื่อยังไม่มีท่อนบน/ล่าง หรือมีแต่ไม่ตรงเรฟ
- เรฟตรวจไม่เจอเสื้อผ้า หรือสไตล์ไม่รู้จัก -> กลับไปจัดลุคแบบปกติ และมี `target_note` บอก
- AI เข้าใจเรฟผ่าน 16 ชิ้นที่ตรวจได้เท่านั้น ไม่ได้ดูสี ลาย หรือเนื้อผ้า

## รูปตัวอย่างสไตล์

วางรูปใน `static/styles/<ชื่อสไตล์>/` เช่น `static/styles/Y2K/1.jpg` (รูปแรกเป็นภาพใหญ่ รูปที่ 2-3 เป็นรูปเล็ก)
สไตล์ที่ยังไม่มีรูปจะใช้ภาพประกอบที่วาดไว้ (ตั้งสีและชิ้นได้ที่ `art` ใน `STYLE_META`) · `GET /api/style-images`
